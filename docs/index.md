# Integración Numérica mediante Cuadratura Gaussiana

## Introducción al Problema

Las integrales definidas no siempre tienen un solución elemental o trivial. Muchas veces resultan siendo complejas y difíciles de evaluar de manera analítica. En este caso vamos a resolver la siguiente integral y evaluarla en el intervalo $[1, 3]$:

$$ \int_{1}^{3} \left( x^6 - x^2 \sin(2x) \right) \, dx $$

Existen diversas maneras de resolver este tipo de ejercicios, pero en este caso estaremos usando la *Cuadratura de Gauss-Legendre*
